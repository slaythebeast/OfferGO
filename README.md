# OfferGO

OfferGO 项目资料库，用于组员协作与老师查阅，集中整理项目说明、参考资料、讨论记录和成果文件。

## 资料导航

| 目录 | 内容 |
| --- | --- |
| [项目说明](docs/) | 项目背景、目标、方案与进度说明 |
| [参考资料](references/) | 文献、课程参考材料、调研资料与来源链接 |
| [讨论记录](meetings/) | 小组讨论、老师反馈、决策与后续任务 |
| [项目成果](deliverables/) | 报告、演示文稿及其他成果文件 |

目前已建立分类目录，项目资料待上传。

## 查阅与更新

- 点击上方目录查阅对应资料，各目录首页列出文件及简要说明。
- 面向查阅的报告和演示文稿可提供 PDF，并保留 Word、PowerPoint 等可编辑源文件。
- 同一份文件更新时尽量保持路径不变，方便组员和老师持续使用同一链接。
- 多份同类文件可采用 `YYYY-MM-DD_主题` 命名，例如 `2026-09-10_讨论记录.md`。
