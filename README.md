# OfferGO

A shared project repository for team collaboration and instructor review, bringing together project documentation, reference materials, meeting notes, and deliverables.

OfferGO 项目资料库，用于组员协作与老师查阅，集中整理项目说明、参考资料、讨论记录和成果文件。

## Project Materials / 资料导航

| Folder / 目录 | Contents | 内容 |
| --- | --- | --- |
| [Project Documentation / 项目说明](docs/) | Project background, objectives, plans, and progress updates | 项目背景、目标、方案与进度说明 |
| [Reference Materials / 参考资料](references/) | Literature, course reference materials, research resources, and source links | 文献、课程参考材料、调研资料与来源链接 |
| [Meeting Notes / 讨论记录](meetings/) | Team discussions, instructor feedback, decisions, and action items | 小组讨论、老师反馈、决策与后续任务 |
| [Deliverables / 项目成果](deliverables/) | Reports, presentations, and other project outputs | 报告、演示文稿及其他成果文件 |

The folders are ready; project materials have not yet been uploaded.

目前已建立分类目录，项目资料待上传。

## Language / 语言

Repository guides are provided in English and Chinese, with English first. Coursework submissions must be in English, as required by the assignment.

仓库说明采用中英双语，英文在前。正式作业按课程要求使用英文。

## Browsing and Updating / 查阅与更新

- Open a folder above to find the relevant materials. Each folder's README serves as an index of files and brief descriptions.  
  点击上方目录查阅对应资料，各目录的 README 作为索引，列出文件及简要说明。

- Reports and presentations can be shared as PDFs for convenient viewing, alongside editable Word or PowerPoint source files.  
  面向查阅的报告和演示文稿可提供 PDF，并保留 Word、PowerPoint 等可编辑源文件。

- When updating an existing file, keep its path unchanged where possible so that team members and instructors can continue using the same link.  
  同一份文件更新时尽量保持路径不变，方便组员和老师持续使用同一链接。

- For a series of similar files, use a name such as `YYYY-MM-DD_topic`, for example `2026-09-10_meeting-notes.md`.  
  多份同类文件可采用“日期_主题”的英文命名方式，例如 `2026-09-10_meeting-notes.md`。
