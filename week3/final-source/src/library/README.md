# 英国项目库前端

- `programs.json`：此前官网资料快照，含来源链接、入学季和基本要求。不得用模拟录取数据推导入学门槛。
- `data.js`：院校、项目扩展字段、课程摘要、虚构案例和讨论数据；筛选、图表统计与模拟问答的纯函数。
- `Library.jsx`：三层页面与 OfferBoard、Community、Assistant 组件。
- `library.css`：模块局部样式；响应式网格由 Tailwind 编译。

路由：`#programs` → `#university/manchester` → `#program/manchester-power`。

当前收藏、案例上报、发帖和评论仅保留在页面运行期间的内存，刷新重置。无请求、账号、消息发送或后台。

替换真实数据时保留项目 ID 的关联关系；案例必须带来源与核实状态。统计仅使用结果为“录取”的记录，985 与 211（非985）分类互斥，均分区间不重叠。海外不同评分制需要单独处理，不能沿用本演示的虚构百分制直接统计。

项目基本信息与课程字段来自官网摘要；AI准备建议、模拟社区数据分别标注，不构成录取判断。QS 排名未核实，不填推测数值。
