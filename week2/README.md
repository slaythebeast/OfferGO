# Week 2 — Programme research and application workflow

## Purpose
This week turns the prototype into a useful planning tool: users can inspect programme-specific information and track requirements separately for each target programme.

## Iterations

4. **04 — UK programme library** (`04-project-library/04-project-library.patch`) — Added the university/programme library and sample programme records, including source links and verification cues. The three-level information structure helps users move from universities to programmes to programme details.
5. **05 — Application dashboard** (`05-application-dashboard/05-application-dashboard.patch`) — Added application progress and task checklists within each target programme. This reflects that document requirements and progress differ by programme, so one global checklist would be misleading.

## 中文说明
第二周重点是把“查项目”和“推进申请”连起来：项目资料有来源提示；材料清单跟随每个目标项目，分别展示进度，避免不同项目的要求混在一起。

Programme examples are demonstration content. Programme requirements change; always follow the linked university pages.
